# Navbatchi — онлайн-запись к частным мастерам в Telegram

Telegram-бот для мастеров в Узбекистане: ногти, брови, ресницы, барберы, массаж, репетиторы.
Клиент сам выбирает услугу и свободное время, при необходимости вносит предоплату **напрямую на карту мастера**,
получает напоминания. Мастер видит записи, статистику и клиентов, а за бота платит подписку.

Один бот обслуживает всех мастеров. У каждого мастера своя ссылка: `t.me/<BOT_USERNAME>?start=m_<slug>`.
Языки: русский и узбекский (латиница).

## Возможности

### Клиент
- Запись по ссылке мастера: услуга → день → время → подтверждение. Показываются только свободные дни и время.
- Видит фото работ, описание и рейтинг мастера (⭐ от 3 отзывов), адрес и точку на карте.
- Предоплата: карта мастера, «Я оплатил» → скриншот → мастер подтверждает. Без скриншота за 30 минут время освобождается.
- Напоминания за 24 ч («Приду / Перенести / Отменить») и за 2 ч (с картой). Тихие часы 22:00–08:00.
- «📋 Мои записи»: перенос и отмена не позже чем за 2 часа. «Мои мастера» — записаться снова в одно касание.
- После визита — оценка ⭐1–5 и отзыв. Через N недель — «Пора снова?» с кнопкой записи.

### Мастер
- Регистрация за 3–5 минут: имя, телефон, услуги, график, предоплата → ссылка, текст для Instagram, QR-код.
- 📅 Сегодня / Завтра / Неделя: каждая запись — карточка с «Перенести» / «Отменить» (клиент получает уведомление).
- ➕ Записать клиента вручную (звонок, личка) и 🚫 закрыть время — бот не даст записаться на занятое.
  Если клиент уже есть в боте (из базы клиентов или по подтверждённому номеру) — он сразу получает
  уведомление и напоминания. Если нет — мастер отправляет ему ссылку-подтверждение (Telegram, WhatsApp, SMS):
  открыв её, клиент подключает запись к себе, получает напоминания и может сам перенести или отменить её.
- Уведомления о новых записях (с кнопками «Открыть» / «Написать клиенту»), отменах, переносах; в 08:00 —
  расписание на день; «клиент не подтвердил» за 3 часа; «Клиент пришёл?» после визита → учёт неявок
  (после 2 неявок клиент записывается только с предоплатой).
- 📊 Статистика за месяц: выручка и визиты с % к прошлому месяцу, средний чек, новые/постоянные клиенты,
  неявки, отмены, рейтинг и отзывы.
- 👥 База клиентов: визиты, потрачено, неявки, история, «Записать снова», «Написать в Telegram».
- 🖼 Профиль (описание, до 6 фото), 📍 адрес и точка на карте, 💳 предоплата, ⚙️ шаг времени, перерыв между
  клиентами, горизонт записи, минимум до записи, «пора снова» через N дней; выходные даты и отпуск диапазоном.
- 💎 Подписка: пробный период, оплата на карту владельца со скриншотом, напоминания за 3 и 1 день.
- 🎁 Пригласить мастера: коллеге +14 дней пробного, пригласившему +30 дней, когда коллега впервые оплатит.

### 📱 Мини-приложение мастера
Открывается в Telegram кнопкой «📱 Открыть приложение» в меню мастера или кнопкой «Приложение» у поля ввода.
- **Записи:** лента дней с числом записей, карточки за день (клиент из бота или вручную, статус, цена),
  «Записать», «Закрыть время», перенос, отмена, «Пришёл / Не пришёл», ссылка для клиента.
- **Клиенты:** поиск по имени и телефону, карточка с историей, «Записать снова».
- **Статистика:** месяц с переключением, выручка и визиты с % к прошлому месяцу, неявки, рейтинг.
- **Проверка предоплаты:** скриншот клиента прямо в карточке записи, «Оплата получена / Оплаты нет».
- **Настройки:** услуги (добавить, изменить, скрыть), график по дням с перерывами («такой же на все рабочие дни»),
  выходные и отпуск, правила записи, предоплата, описание, фото работ (до 6, с телефона), адрес и точка на карте
  (геопозиция или ссылка Google/Яндекс Карт), ссылка + текст для Instagram + QR-код, «Пригласить мастера»,
  подписка (реквизиты и скриншот оплаты — админу на проверку), язык. Отзывы — из статистики.
- Всё, что мастер делает в боте, есть и в приложении; бот остаётся для уведомлений, регистрации и записи клиентов.
  Картинки хранятся в Telegram (file_id), как и в боте.
- Тема (светлая/тёмная) и язык — как в Telegram и в боте.

Вход — по подписи Telegram (`initData`, проверяется токеном бота, действует сутки); каждый мастер видит только свои
данные. Клиенты получают те же уведомления, что и при изменениях через бота.

### Владелец сервиса (`ADMIN_ID`)
- `/admin`: статистика, список мастеров (подписка, активность за 30 дней), оплаты подписок на проверке.
- Скриншоты оплат подписки с кнопками «Подтвердить / Отклонить» (+30 дней).
- `/extend <мастер> <дни>` — продлить вручную (мастер: slug из ссылки, Telegram ID или id).
- `/broadcast` — рассылка всем мастерам с предпросмотром.
- Уведомления о каждом новом мастере и о сбоях бота (не чаще раза в 10 минут на тип).

## Деньги

Деньги клиентов за услуги идут **только** на карту мастера. Бот их не принимает и не пересылает — показывает
реквизиты мастера и пересылает мастеру скриншот перевода. На карту владельца (`SUB_CARD`) приходит только
оплата подписки мастерами.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните. Файл `.env` не коммитится.

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `MONGODB_URI` | строка подключения MongoDB (Atlas или Railway) |
| `ADMIN_ID` | Telegram ID владельца сервиса ([@userinfobot](https://t.me/userinfobot)) |
| `SUB_PRICE` | цена подписки в сумах за 30 дней (по умолчанию 50000) |
| `SUB_CARD` | номер карты владельца для оплаты подписки |
| `SUB_CARD_NAME` | имя владельца этой карты |
| `TRIAL_DAYS` | пробный период в днях (по умолчанию 30) |
| `PORT` | порт сайта мини-приложения (Railway задаёт сам; по умолчанию 3000) |
| `WEBAPP_URL` | адрес мини-приложения; на Railway не нужен — берётся из `RAILWAY_PUBLIC_DOMAIN` |

## Локальный запуск

Нужен Node.js 20+ и MongoDB.

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN, MONGODB_URI, ADMIN_ID
npm start
npm test               # unit-тесты (node:test)
```

**MongoDB Atlas (бесплатно):** [cloud.mongodb.com](https://cloud.mongodb.com) → кластер M0 → Database Access
(пользователь) → Network Access `0.0.0.0/0` → Connect → Drivers → строка подключения с именем базы после `.net/`.

## Деплой на Railway

1. **New Project** → **Deploy from GitHub repo** → этот репозиторий. MongoDB можно добавить в тот же проект.
2. **Variables** → переменные из таблицы выше (`MONGODB_URI` = `${{MongoDB.MONGO_URL}}/booking?authSource=admin`).
3. Railway выполнит `npm install` и `npm start`. Бот работает через long polling.
4. Для мини-приложения: **Settings → Networking → Generate Domain** (порт — тот, что в `PORT`). Без домена бот работает,
   просто кнопки приложения нет.
5. В логах: `[jobs] Задачи запущены`, `[web] Мини-приложение на порту …` и `[bot] Запущен как @имя_бота`.

Бот должен работать в **одном экземпляре** (1 replica). При деплое старая и новая копия несколько секунд работают
одновременно — бот сам пережидает `409 Conflict`. На маленьком томе MongoDB (бесплатный Railway, 500 МБ) бот сам
снижает порог свободного места для построения индексов.

## Расписание фоновых задач (Asia/Tashkent)

| Когда | Что |
|---|---|
| каждую минуту | неоплаченные вовремя записи → `expired`, время освобождается |
| каждые 5 минут | напоминания клиентам (24 ч, 2 ч), «клиент не подтвердил» (3 ч; по утренним записям — накануне с 20:00), «Клиент пришёл?» (через 1 ч). Тихие часы 22:00–08:00 |
| 08:00 | мастерам — расписание на день |
| 10:00 | мастерам — подписка заканчивается через 3 / 1 день |
| 12:00 | клиентам — «Пора снова?» через `rebookDays` после визита |
| 00:05 | истёкшие подписки → `expired` |
| 03:30 | записи без ответа «пришёл / не пришёл» 2 суток → `completed` |

Каждое напоминание отправляется один раз: флаг в `booking.reminders` ставится атомарно до отправки.

## Как устроено

- **Слоты** (`services/slots.js`): график, перерывы, выходные, шаг, перерыв между клиентами, минимум до записи,
  горизонт. Чистые функции покрыты тестами.
- **Двойная запись исключена:** запись создаётся под короткой блокировкой мастера (`bookingLockUntil`, снимается
  только своя) с повторной проверкой слота. Транзакции не нужны — работает на MongoDB без replica set.
- **Время:** в базе — UTC, пользователю — `Asia/Tashkent`. Выходные даты мастера — локальные `YYYY-MM-DD`.
- **Ручные записи и закрытое время** — тоже `Booking`: `kind: 'block'` для закрытого времени,
  `manualName/manualPhone` для клиента без Telegram.
- **Надёжность:** повтор при лимитах Telegram (`@grammyjs/auto-retry`), сообщения длиннее лимита обрезаются по
  строке, ошибки не роняют бота и приходят владельцу.

## Тексты и переводы

Все тексты — в `locales/ru.js` и `locales/uz.js`, в коде строк для пользователя нет. Подстановки `{name}`,
склонения в русском — `{days#день|дня|дней}`. Тест `tests/locales.test.js` проверяет, что в обоих языках
одинаковые ключи и подстановки и что все ключи из кода существуют.

Для вычитки носителем языка: `node scripts/export-texts.js` → `docs/texts-review.md` (таблица «русский | узбекский»).

## Структура

```
index.js              запуск: MongoDB, индексы, бот, фоновые задачи, 409 при деплое
config.js             переменные окружения
bot/
  index.js            сборка: сессии, HTML, лимиты Telegram, обработка ошибок
  common.js           /start, ссылки m_ (мастер), r_ (приглашение), b_ (подтверждение ручной записи), язык, роль
  master/             регистрация, меню, записи, ручные записи, услуги, график, выходные, настройки,
                      предоплата, адрес, профиль, ссылка и QR, статистика, клиенты, подписка, приглашения
  client/             запись, «Мои записи», предоплата, подключение ручной записи по ссылке
  admin/              /admin, /extend, /broadcast, оплаты подписок
  reminders.js        напоминания, «Клиент пришёл?», утреннее расписание, «пора снова?»
  reviews.js          оценки и отзывы
  jobs.js             расписание фоновых задач
  alerts.js           сообщения владельцу (новые мастера, сбои)
web/                  сервер мини-приложения: проверка initData, API /api/*
webapp/               мини-приложение: index.html, app.js, app.css, i18n.js (без сборки)
models/               Master, Client, Booking, SubscriptionPayment, Session
services/             slots, booking, payments, reminders, subscription, referral, stats, clients
locales/              ru.js, uz.js, index.js (t, склонения)
utils/                time (Asia/Tashkent), validate, ids
tests/                node:test
scripts/              export-texts.js
```
