# Бот онлайн-записи к частным мастерам

Telegram-бот для мастеров в Узбекистане: ногти, брови, ресницы, барберы, массаж, репетиторы.
Клиент сам выбирает услугу и свободное время, вносит предоплату **напрямую на карту мастера** и получает напоминания.
Мастер платит за бота подписку.

Один бот обслуживает всех мастеров. У каждого мастера своя ссылка: `t.me/<BOT_USERNAME>?start=m_<slug>`.

Языки: русский и узбекский (латиница). Все тексты — в `locales/ru.js` и `locales/uz.js`.

## Статус по этапам

| Этап | Что | Статус |
|---|---|---|
| 1 | Модели, регистрация мастера, услуги, график, выходные, предоплата (настройка), выбор языка | ✅ |
| 2 | `services/slots.js` + тесты | ✅ |

| 6 | Подписка и админ | ⏳ |
| 7 | Вычитка узбекских текстов | ⏳ |

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните. Файл `.env` не коммитится.

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `MONGODB_URI` | строка подключения MongoDB Atlas, например `mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net/booking` |
| `ADMIN_ID` | ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)) |
| `SUB_PRICE` | цена подписки в сумах в месяц (по умолчанию 50000) |
| `SUB_CARD` | номер вашей карты для оплаты подписки мастерами |
| `SUB_CARD_NAME` | имя владельца этой карты |
| `TRIAL_DAYS` | длина пробного периода в днях (по умолчанию 30) |

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN, MONGODB_URI, ADMIN_ID
npm start
npm test               # unit-тесты (node:test)
```

### MongoDB Atlas (бесплатно)

1. [cloud.mongodb.com](https://cloud.mongodb.com) → создать бесплатный кластер M0.
2. **Database Access** → добавить пользователя с паролем.
3. **Network Access** → `Add IP Address` → `0.0.0.0/0` (Railway не даёт постоянный IP).
4. **Connect** → Drivers → скопировать строку, подставить пароль, после `.net/` дописать имя базы (например `booking`).

## Деплой на Railway

1. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → выбрать этот репозиторий.
2. **Variables** → добавить все переменные из таблицы выше.
3. Railway сам выполнит `npm install` и `npm start` (`node index.js`). Домен и порт не нужны — бот работает через long polling.
4. В логах должно появиться `[bot] Запущен как @имя_бота`.

Важно: бот должен работать **в одном экземпляре** (1 replica). Два процесса с одним токеном будут конфликтовать.

## Как проверить этап 1

1. Напишите боту `/start` → выберите язык → «✂️ Я мастер».
2. Пройдите регистрацию: имя → телефон (кнопкой) → услуги → график («Одинаково для всех будних») → предоплата.
3. Бот выдаст ссылку и текст для Instagram, откроется меню мастера.
4. В меню: услуги (изменить цену/длительность, отключить), график (часы, перерывы, выходные даты, настройки записи), предоплата, ссылка, подписка, язык.
5. Откройте свою ссылку с другого аккаунта: бот попросит язык и покажет имя мастера (сама запись — этап 3).

## Как проверить этап 3

1. У мастера **выключите предоплату** (с предоплатой запись появится на этапе 4).
2. Откройте ссылку мастера с другого аккаунта: имя → телефон → услуга → день → время → «Записаться».
3. Мастер получит «🆕 Новая запись», запись видна в «📅 Сегодня / Завтра / Неделя».
4. Клиент: «📋 Мои записи» → запись → «🔄 Перенести» или «❌ Отменить» (не позже чем за 2 часа). Мастер получает уведомление.
5. Мастер тоже может записываться к другим мастерам: «📋 Мои записи (как клиент)» в его меню.

Защита от двойной записи: на время создания записи мастер блокируется (`bookingLockUntil`),
слот проверяется заново под блокировкой. Транзакции не нужны — подходит MongoDB без replica set.

```

bot/

  middleware.js       загрузка пользователя/мастера, язык
  steps.js            пошаговый ввод (имя, цена, время…)
  ui.js               вывод экранов, форматирование
  common.js           /start, выбор языка и роли, главное меню
  master/             регистрация, меню, услуги, график, выходные, настройки, предоплата, ссылка, записи, подписка

models/               Master, Client, Booking, SubscriptionPayment, Session
services/             slots.js, reminders.js, subscription.js (следующие этапы)
locales/              ru.js, uz.js, index.js (функция t)

tests/                node:test
```

## Время

В базе всё хранится в UTC, пользователю показывается в `Asia/Tashkent` (`utils/time.js`).
Отдельные выходные мастера (`daysOff`) хранятся как локальные даты `YYYY-MM-DD`.

## Деньги

Деньги клиентов за услуги идут **только** на карту мастера. Бот их не принимает и не пересылает —
он показывает клиенту реквизиты мастера и пересылает мастеру скриншот перевода.
На карту владельца сервиса (`SUB_CARD`) приходит только оплата подписки мастерами.
